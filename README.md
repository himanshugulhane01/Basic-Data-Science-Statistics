# Data Science Practicals Using Python

## About This Repository

This repository contains a collection of hands-on Data Science practicals implemented using Python and Jupyter Notebook.

The objective is to develop practical knowledge of data acquisition, data preprocessing, statistical analysis, data visualization, and fundamental machine learning algorithms.

## Practical Contents

| No. | Practical | Topics Covered |
|---|---|---|
| 01 | Data Acquisition | Collecting and loading datasets |
| 02 | Exploratory Data Analysis | Understanding and exploring datasets |
| 03 | Identification of Missing Values | Detecting missing data |
| 04 | Missing Value Treatment | Handling missing data |
| 05 | Statistical Description | Descriptive statistical analysis |
| 06 | Sampling and Population | Population and sampling techniques |
| 07 | NumPy Arrays | 1D, 2D and multidimensional arrays |
| 08 | Data Visualization | Graphs and visual representation |
| 09 | Central Tendency | Mean, Median, Mode, Variance and Standard Deviation |
| 10 | Simple Linear Regression | Salary prediction using regression |
| 11 | Logistic Regression | Classification using logistic regression |
| 12 | K-Nearest Neighbors | Classification using KNN |

## How to Run

1. Clone this repository.
2. Install Python and Jupyter Notebook.
3. Install the required libraries:

```bash
pip install numpy pandas matplotlib seaborn scikit-learn jupyter
```

4. Launch Jupyter Notebook:

```bash
jupyter notebook
```

5. Open any practical notebook and execute the cells.
