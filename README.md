# Basic-Data-Science-statistics
A collection of Jupyter Notebook programs focused on Data Science and Statistics practicals using Python. This project covers data acquisition, Exploratory Data Analysis (EDA), missing value identification and treatment, statistical descriptions, sampling and population, NumPy arrays, data visualization, measures of central tendency (mean, median, and mode), simple linear regression, logistic regression, and K-Nearest Neighbors (KNN) classification.

**Tools & Technologies:** Python, Jupyter Notebook, NumPy, Pandas, Matplotlib, Seaborn, and Scikit-learn.
